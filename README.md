# Level Up Learning

Build a complete, production-quality web platform called STARBOUND — a sleek, minimalistic course marketplace and learning platform built specifically for gamers and gaming education.

The platform allows anyone to create, publish, discover, purchase, and consume gaming courses. Course creation must be completely free. Creators only pay a commission when they successfully sell a course.

1. Core Business Model

STARBOUND is a gaming-focused course marketplace.

Creators:

Can create an account for free.

Can create unlimited courses for free.

Can publish courses without paying upfront.

Can create courses using:

Video lessons

Text lessons

Images

A combination of video, text, and images

Can set their own course price.

Can edit and update their courses at any time.

Can see their sales, students, revenue, and course analytics from a creator dashboard.

STARBOUND takes an 18% commission from every course purchase.

Example:

Course price: $20

Creator receives: $16.40

STARBOUND receives: $3.60

Clearly communicate this model to creators. There should be no hidden creator subscription fee.

30. Important Product Principle

The interface should always prioritize clarity and speed.

without needing technical knowledge.
